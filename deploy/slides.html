01. Tổng quan & Bản chất

Mục tiêu Cốt lõi của Môn học Linux

Ứng dụng Web Chat là công cụ kiểm thử, trọng tâm là biến máy tính thành máy chủ đạt chuẩn công nghiệp.

05. Kỹ thuật Trọng tâm

Cấu hình Web Server Nginx & Systemd

Những điểm mấu chốt kỹ thuật được thiết lập trực tiếp trên hệ điều hành Ubuntu.

NG Cấu hình Nginx (deploy/nginx/webchat.conf)
# Bắt tay WebSocket không bị drop kết nối
proxy_set_header Upgrade $http_upgrade;
proxy_set_header Connection "upgrade";
proxy_http_version 1.1;
# Chống lỗi 404 khi người dùng F5 tải lại trang
try_files $uri $uri/ /index.html;

Giữ kết nối WebSocket liên tục qua cổng 80/443 và phục vụ SPA mượt mà.

SD Quản lý Dịch vụ (deploy/systemd/webchat.service)
# Chạy dưới quyền User an toàn (Least Privilege)
User=chatuser
Group=chatuser
# Tự động hồi sinh khi crash hoặc bị kill -9
Restart=always
RestartSec=5

Bảo mật không dùng root, tự động khởi động cùng hệ điều hành.

Khả năng chịu lỗi: Đã thử nghiệm lệnh sudo kill -9, Systemd tự phục hồi sau đúng 5 giây. Self-Healing System
06. Cơ sở Dữ liệu & Tự động hóa

MySQL Chuẩn 3NF & Sao lưu Crontab

Mô hình dữ liệu quan hệ hoàn chỉnh kết hợp chiến lược phòng ngừa thảm họa.

CSDL MySQL (webchat_db • utf8mb4)

users: id (UUID), username, status (ONLINE/OFFLINE), lastIp, lastSeen
rooms: id (UUID), name, type (PUBLIC/PRIVATE), description
messages: id (UUID), room, user, text, ipAddress, createdAt

Ghi lại chính xác IP thật của máy gửi tin lấy qua Nginx.

Tự động hóa Sao lưu (Crontab)

# Chạy lúc 02:00 sáng hàng ngày
0 2 * * * /deploy/scripts/backup.sh
# Xuất bản sao lưu nén qua mysqldump
mysqldump -u chatuser webchat_db | gzip > ...sql.gz
# Tự xóa file cũ hơn 7 ngày chống đầy đĩa
find /var/backups -mtime +7 -delete

Có sẵn script restore_db.sh khôi phục CSDL khi gặp sự cố.

Toàn vẹn dữ liệu: Hỗ trợ tiếng Việt đầy đủ và icon emoji thông qua charset utf8mb4. Disaster Recovery Ready
